# Плагины Paint.NET

## Обводка текста

Нужно скопировать файл 
```
.\outline\Outline Object.dll
```

в папку

```
C:\Program Files\paint.net\Effects\
```

Есть еще разные плагины, они доступны в архиве
```
.\outline\pyrochild.2020-11-21.zip
```

## PDF

Совместимо только с Paint.NET 5.1 и поздне
Разархивировать папку
```
.\pdf\PdfFileTypePlugin\
```

по пути

```
C:\Program Files\paint.net\FileTypes\
```
